Everything needed to build my hackpad:

- 9× Cherry MX switches
- 9× DSA keycaps
- 4× M3×5×4 heat-set inserts
- 6× M3×16 SHCS bolts
- 9× 1N4148 DO-35 diodes
- 1× 0.91" 128×32 OLED display
- 1× Seeed XIAO RP2040
- 1× case(top)
- 1× case(bottom)
